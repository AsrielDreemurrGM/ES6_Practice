<h1>Prática com ES6</h1>
<p>This README is also available in <a href="./README.md">English</a>.</p>
<p>
  Este projeto foi desenvolvido para praticar JavaScript moderno (ES6+) implementando um filtro de alunos.
  Utiliza classes, métodos de array e funções arrow para filtrar alunos com notas maiores ou iguais a 6.
  O Babel foi configurado para transpilar o código e garantir compatibilidade com navegadores usando o <code>@babel/preset-env</code>.
</p>
<h2>🚀 Funcionalidades</h2>
<ul>
  <li>Define uma classe para representar o nome e a nota do aluno;</li>
  <li>Utiliza <code>map()</code> para transformar objetos brutos em instâncias da classe;</li>
  <li>Filtra alunos com nota mínima utilizando <code>filter()</code>;</li>
  <li>Utiliza funções arrow e outras funcionalidades do ES6;</li>
  <li>Código é transpilado com Babel para suportar mais navegadores;</li>
  <li>Modo <code>watch</code> habilitado via Babel CLI para facilitar o desenvolvimento.</li>
</ul>
<h2>🧠 O Que Foi Aprendido</h2>
<ul>
  <li>Criação e uso de classes e construtores no ES6;</li>
  <li>Transformação e filtragem de arrays com <code>map()</code> e <code>filter()</code>;</li>
  <li>Uso de arrow functions para sintaxe mais concisa;</li>
  <li>Configuração do Babel com <code>@babel/cli</code> e <code>@babel/preset-env</code>;</li>
  <li>Escrita de JavaScript moderno com compatibilidade garantida por meio de transpile.</li>
</ul>
<h2>🛠️ Tecnologias Utilizadas</h2>
<ul>
  <li>JavaScript (ES6+)</li>
  <li>Babel CLI</li>
  <li>Babel Preset Env</li>
  <li>Node.js (NPM)</li>
</ul>
