<h1>ES6 Practice</h1>
<p>Este README também está disponível em <a href="./README.pt-br.md">Português</a>.</p>
<p>
  This project was developed to practice modern JavaScript (ES6+) by implementing a student filter.
  It uses classes, array methods, and arrow functions to filter students with grades greater than or equal to 6.
  Babel is configured to transpile the code for browser compatibility using the <code>@babel/preset-env</code>.
</p>
<h2>🚀 Features</h2>
<ul>
  <li>Defines a class to represent student name and grade;</li>
  <li>Uses <code>map()</code> to transform raw objects into class instances;</li>
  <li>Filters students based on minimum grade using <code>filter()</code>;</li>
  <li>Uses arrow functions and other ES6 syntax elements;</li>
  <li>Code is transpiled using Babel for wider browser support;</li>
  <li><code>watch</code> mode enabled via Babel CLI for development ease.</li>
</ul>
<h2>🧠 What Was Learned</h2>
<ul>
  <li>Creating and using ES6 classes and constructors;</li>
  <li>Transforming and filtering arrays using <code>map()</code> and <code>filter()</code>;</li>
  <li>Using arrow functions for concise syntax;</li>
  <li>Setting up and configuring Babel with <code>@babel/cli</code> and <code>@babel/preset-env</code>;</li>
  <li>Writing modern JavaScript that compiles for broader browser compatibility.</li>
</ul>
<h2>🛠️ Technologies Used</h2>
